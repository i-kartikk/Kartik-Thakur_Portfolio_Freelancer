# Kartik Thakur — Freelance Web Developer Portfolio

Vercel-ready React + Vite portfolio.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

Import this repository into Vercel. Framework: Vite. Build command: `npm run build`. Output directory: `dist`.

## Portfolio structure

- Live Work: InfoTag, FiguredOutAI
- Showcase Templates: House of Aureoné, Café, Real Estate, Interior Designer, Hotel Management

The showcase templates are explicitly labeled as concepts/templates and are not presented as commissioned client projects.
