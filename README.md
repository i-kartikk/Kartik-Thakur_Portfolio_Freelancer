# Kartik Thakur — Freelance Web Developer Portfolio

Vercel-ready React + Vite portfolio.

## Included
- Two production projects: InfoTag and FiguredOutAI
- Five showcase templates clearly separated from production work
- Two compact project cards per row on desktop
- Responsive mobile layout
- Framer Motion animations
- Lucide icons
- Direct live project links

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deploy to Vercel

Import the repository into Vercel. Vercel will detect Vite automatically.

Build command: `npm run build`
Output directory: `dist`

## Notes
The portfolio labels House of Aureoné, Café, Real Estate, Interior Designer, and Hotel Management as showcase templates/concepts, not client projects.
